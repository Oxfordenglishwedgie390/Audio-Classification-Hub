Installation

Install from the local wheel file you just downloaded:

$ pip install voiceauth.whl

Or install the latest release from PyPI:

$ pip install voiceauth

Quick Start

from voiceauth import VoiceAuth

# Initialize with your embedding
auth = VoiceAuth(
    embedding_path="user_embed.npy",
    threshold=0.82  # adjust sensitivity
)

# Verify a speaker
result = auth.verify("audio_sample.wav")
print(result)
# → {"authenticated": True,
#    "confidence": 0.94,
#    "latency_ms": 43}

INFO
The threshold value controls sensitivity. Higher = stricter. Recommended range: 0.80–0.88

VoiceAuth() — Constructor

Creates an authenticator bound to a stored voice embedding.

Parameter Type Default Description
embedding_path str required Path to .npy embedding
threshold float 0.82 Cosine similarity cutoff
sample_rate int 16000 Expected audio sample rate
device str "cpu" "cpu" or "cuda"

.verify() — Method

Signature: auth.verify(audio_path: str) → dict

{
  "authenticated": bool,
  "confidence": float,  # 0.0 to 1.0
  "latency_ms": int
}

WARNING
Audio file must be mono, 16kHz WAV. Use preprocess_audio() helper if unsure.

.enroll() — Method

Register a new voiceprint from one or more samples. Signature: auth.enroll(samples: list[str]) → np.ndarray

embed = auth.enroll(["s1.wav", "s2.wav", "s3.wav"])
np.save("user_embed.npy", embed)

.batch_verify() — Method

1:N speaker search across many enrolled embeddings. Signature: auth.batch_verify(audio, embeds: dict) → dict

FastAPI Integration

from fastapi import FastAPI, UploadFile
from voiceauth import VoiceAuth

app = FastAPI()
auth = VoiceAuth("embed.npy")

@app.post("/verify")
async def verify_voice(file: UploadFile):
    content = await file.read()
    result = auth.verify_bytes(content)
    return result

Django Integration

Wrap VoiceAuth in a singleton service and call it from a DRF view. Initialize once at app startup to avoid reloading the model per request.

Flask Integration

from flask import Flask, request
auth = VoiceAuth("embed.npy")

@app.route("/verify", methods=["POST"])
def verify():
    f = request.files["audio"]
    return auth.verify_bytes(f.read())

Node.js (wrapper)

Spawn the Python CLI from Node via child_process, or call your FastAPI endpoint over HTTP. A native wrapper is on the roadmap.

Threshold Tuning

Lower thresholds reduce false rejects (better UX); higher thresholds reduce false accepts (better security). Tune against your own balanced test set.

Threshold Behavior Use case
0.75 Lenient Low-risk IVR menus
0.82 Balanced Default / most apps
0.88 Strict Financial / admin access

Embedding Export

Embeddings are portable .npy float32 arrays of shape (192,). Store them in your DB as base64 or a blob — no cloud dependency required.

Offline Mode

The wheel bundles the ECapa weights. After install, no network access is required — perfect for air-gapped and on-prem deployments.
